# Systems / software / archives

- Belial — Max/MSP live computer music / sound-art platform.
- Hiro — procedural Japanese lyric-to-UST generator.
- eli_lab Pattern Generator — deterministic procedural graphics workstation.
- eli_lab SynthV Custom Scripts — vocal-tuning laboratory.
- eli_lab Pipeline Hub — Blender production automation.
- eli_lab Multimedia Framework — project, asset, validation and documentation workspace.
- eli_lab MV — private audio-reactive video editor.
- JIHANKI — interactive vending-machine archive.
- PARAZIT — separate relational gallery/archive system.
- the Poster / Formatter / Previewer — small utility repositories; purpose still needs project-level documentation.

## Architectural continuity
classification → generation → transformation → archive

Pattern Generator and Hiro turn rules into creative outputs. Pipeline Hub turns production workflow into software. Multimedia Framework turns project files into semantic entities. JIHANKI turns archive data into a machine interface. PARAZIT turns exhibition/provenance data into a relational graph.

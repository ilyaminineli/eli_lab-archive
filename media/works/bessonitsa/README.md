# Бессоница / Insomnia

Media folder for canonical archive record bessonitsa (2022).

This folder is reserved for real archival media. Suggested files:
- 01-cover.* — primary image / poster
- 02-documentation-*.* — exhibition or process documentation
- 03-process-*.* — sketches, screenshots, working material
- 04-still-*.* — selected stills / details
- 05-context-*.* — contextual or source imagery

Keep original source material separate from the selected images used by the public archive record. Once files are added, update data/media.json so the record can display them.

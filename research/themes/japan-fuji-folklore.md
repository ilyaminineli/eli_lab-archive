# Theme: Japan / Fuji / folklore

## Cluster
- JIHANKI — interactive archive originating from SAIKONEON / Lake Saiko, Yamanashi.
- 山は覚えている / The Mountain Remembers — mountain/landscape memory, field recordings and synthetic voices.
- 富士山六大妖怪 / Six Yokai of Mount Fuji — invented folklore / Fuji research branch.
- Fuji Sonic Pi materials documented inside JIHANKI.
- Kagome Kagome — Japanese nursery/folk-song reference within the UTAU branch.
- Nature (2019) — experimental video built around Japanese haiku.
- 2026 voice-synthesis works overlap the Japan branch through Japanese language and character systems.

## Relationship hypothesis
The Japan work is not only a geographic episode. It combines field observation, folklore, synthetic voice, sound programming and archive interfaces. JIHANKI provides the clearest formal bridge between location research and the archive-as-machine idea.

## Preserve separately
Actual field observations, fictional yokai documentation and later aesthetic works should not be collapsed into one project. Link them through the theme graph.

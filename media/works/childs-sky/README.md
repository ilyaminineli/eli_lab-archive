# 子供の空 / Child's Sky

Reserved media directory for the canonical archive record `childs-sky`.

Suggested filenames:
- 01-cover.* — primary image / poster
- 02-documentation-*.* — exhibition or process documentation
- 03-process-*.* — sketches, screenshots, working material
- 04-still-*.* — selected stills / details
- 05-context-*.* — contextual or source imagery

Keep large source images here and reference the final selected assets from the work record. Do not use the YouTube thumbnail as a substitute once archival imagery is available.

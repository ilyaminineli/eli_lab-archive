## 13. Design research for the new archive

The supplied hardware photograph is a formal reference, not an asset.

Translate these physical characteristics into UI:
- matte painted-metal faceplates
- black dividing lines
- cream/off-white knobs
- dark engraved technical labels
- small tick marks
- red indicator lamps
- screws / fasteners
- separate functional compartments
- analog meter / gauge
- imperfect physical edges
- high information density without visual chaos
- metal + paper label + plastic knob + ink

### Blueprint layer
- construction lines
- grids
- coordinate references
- registration marks
- technical annotations
- module numbering

### Console layer
- faceplates
- knobs
- switches
- indicator lamps
- meter scales
- beveled borders
- screws
- inset shadows
- tactile buttons

### Archive layer
- paper documents
- labels
- photographs
- typed captions
- handwritten annotations
- provenance stamps
- edition / year / medium metadata

Goal: **skeuomorphic artist archive**, not generic retro web.
